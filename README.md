## system-control-sandbox
Python-based research environment for exploring stochastic and risk-sensitive control methodologies. Current focus is on multi-agent and nonlinear Model Predictive Control (nMPC) formulations. This is a Python-based research environment for exploring probabilistic and risk-aware extensions of multi-agent model predictive control. Validated ideas are intended to be ported into a production-grade C++ framework (private collaborative codebase).

This repository focuses on:
- Multi-agent nMPC problem formulations.
- Localized vs. global optimization of deterministic problem formulations.
- Control methodologies optimized for random scheduling and task duration.
- Other problems and questions that come up along the way.

## Motivation

Classical multi-agent MPC is typically deterministic. This sandbox investigates how a system can account for probabilistic modeling (e.g. random task initiation, duration, delays, or random availability and overall utility maximization).
